### Features
- 2 Players mode or play vs Computer (Easy / Medium / Hard - Hard uses minimax and never loses)
- Winning line highlight + symbols animation
- Undo last move
- Sound effects (Web Audio API, no files) with mute button
- Scores & settings saved in localStorage + clear scores button
